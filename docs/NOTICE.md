# Pemberitahuan

CPU game dikompilasi ulang secara lokal dari ROM NTSC-U milik pengguna dengan N64Recomp (MIT, Copyright (c) 2024 Wiseguy, commit `598ce208`). Kode hasil rekompilasi dan ROM tidak boleh masuk distribusi publik.

APK di `artifacts/` adalah build lokal untuk uji. Kunci di `artifacts/debug.keystore.pem` adalah kunci debug, bukan tanda tangan rilis.

Grafis di runtime ini adalah interpreter display-list F3DEX2 di CPU. Bukan RT64. Bukan Vulkan. N64ModernRuntime tidak terpasang.
